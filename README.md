# EARR — Easy Anti-Reflux Recipes

EARR is a personal recipe collection for meals designed around an anti-reflux diet. Each recipe defaults to its reflux-conscious version and may later include a traditional version. The site will also publish high-level educational material about reflux, ingredients, and food choices.

## Architecture

- Go modular monolith with server-rendered `html/template` pages
- HTMX for progressively enhanced interactions
- Plain CSS organized around design tokens
- SQLite through `database/sql` and `modernc.org/sqlite`
- SQL-first data access generated by `sqlc`
- Goose SQL migrations
- Markdown educational content stored in Git
- Distroless, non-root production container

The domain model is documented in [`docs/diagrams/recipe-data-model.mmd`](docs/diagrams/recipe-data-model.mmd). Accepted decisions and their trade-offs live in [`docs/adr`](docs/adr).

Public deployments must remain read-only until authentication and authorization are deliberately introduced.

## Prerequisites

- [mise](https://mise.jdx.dev/)
- Docker
- Git

Install the pinned toolchain and hooks:

```sh
mise trust
mise install
pre-commit install
```
